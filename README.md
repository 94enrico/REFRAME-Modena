# REFRAME Modena

Code for the REFRAME study of obesity in people living with HIV attending the Modena HIV Metabolic Clinic.

- [Original analysis](original_analysis/README.md) contains the R scripts used for the initial submission.
- [Peer review](review_analysis/README.md) contains the revised manuscript analyses and the additional analyses requested by the reviewers.

The original code classified hepatic involvement as CAP ≥248 dB/m with liver stiffness <8 kPa, or liver-to-spleen ratio <1.1 with FIB-4 ≤1.45. The review follows Supplementary Table 1 and uses stiffness ≥8 kPa and FIB-4 >1.45, respectively. Each pair requires both measurements.

The two analyses have separate working directories. The clinical workbooks, participant-level extracts and fitted models are held by the study team.
